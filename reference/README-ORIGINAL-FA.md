# معماری تحویل بیوتیا ۴

## Core

- `core/beautia.zip`: پوسته و رابط کاربری.
- `core/beautia-core.zip`: موتور رزرو، انواع محتوا، پنل مدیریت، ۳۵ ویجت Elementor Free و مدیریت بسته‌های دمو.
- هیچ افزونه پولی یا Elementor Pro برای قابلیت‌های اصلی لازم نیست.

## Core Demos

هر ZIP در `core-demos/` شامل `manifest.json`، فایل امن `demo-data.json` و پوشه `media/` همان دمو است. کاربر آن را از «بیوتیا ← بسته‌های دموی Core» نصب و سپس با درون‌ریز بومی فعال می‌کند.

## Standalone Duplicator Demos

برای هر دمو پوشه‌ای جدا در `standalone-demos/` داریم. خروجی نهایی شامل `installer.php` و آرشیو Duplicator همان سایت (`.zip` یا `.daf`) است. این خروجی‌ها پس از تأیید بصری تک‌تک دموها ساخته می‌شوند تا داده قدیمی وارد بسته نشود.

## قواعد انتشار

- نسخه قالب، Core، manifest دمو و Duplicator یکسان است.
- هیچ کلید لایسنس، حساب واقعی، ایمیل شخصی، لاگ پیامک یا رزرو واقعی داخل بسته نیست.
- پیش از خروجی، کش، revision، transient و فایل موقت پاک می‌شود.
- هر Duplicator روی دیتابیس خالی نصب آزمایشی می‌شود و سپس حذف `installer.php` بررسی می‌گردد.
